# Small Python Projects

This repository contains a collection of small projects developed in Python for practice, learning, and experimentation. Each folder contains an independent mini-project with its own purpose, functionality, and logic.

## Projects

- [`alu_games`](./alu_games): Small logic-based games for practice and fun.
- [`authentication_system`](./authentication_system): A basic user authentication system with login and password handling.
- [`calculator`](./calculator): A simple calculator built using Python.
- [`DolarXReal`](./DolarXReal): Converts USD to BRL using current exchange rates.
- [`draw_numbers`](./draw_numbers): A random number generator project.
- [`jokenpo`](./jokenpo): A Rock-Paper-Scissors game (known as "Jokenpô" in Portuguese).
- [`secret_SANTA`](./secret_SANTA): A script to organize a Secret Santa gift exchange automatically.
- [`shopping_cart`](./shopping_cart): Simulates a basic shopping cart system.
- [`tic_tac_toe`](./tic_tac_toe): A simple two-player Tic Tac Toe game.
- [`ticket_purchase`](./ticket_purchase): A ticket purchase simulation system.
- [`to_do_list`](./to_do_list): A command-line To-Do list app to manage tasks.
- [`two_factors_API`](./two_factors_API): API simulation for two-factor authentication.
- [`user_registration`](./user_registration): Registers new users with form validation.
- [`users_database`](./users_database): Manages a basic user database with read/write operations.
